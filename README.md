# Усиков: система учета брака

Учебный проект УП03, вариант 24: информационная система для учета брака с целью прогнозирования закупок качественного товара.

## Состав

- `WpfAppUP3/` — исходный код WPF-приложения на C#.
- `WpfAppUP3/UP03_create.sql` — создание базы данных и таблиц.
- `WpfAppUP3/UP03_insert.sql` — тестовое заполнение базы данных.
- пояснительная записка и презентация — материалы проектной работы.

## Запуск

1. Выполнить SQL-скрипты на Microsoft SQL Server.
2. Открыть `WpfAppUP3.sln` в Visual Studio 2022.
3. Собрать конфигурацию `Debug` и запустить `WpfAppUP3.exe`.

Приложение использует .NET Framework 4.7.2, WPF и ADO.NET.

## Тестовые роли

- `admin / admin` — администратор.
- `manager / manager` — менеджер по закупкам.
- `proizvod / proizvod` — производство.

> Пароли подключения к учебной базе данных не хранятся в репозитории. Перед запуском задайте параметры подключения локально.
